# Techguns — Unofficial 1.20.1 Port

Unofficial port of **Techguns 2** to **Minecraft 1.20.1 (Forge)**: guns, armors, machines, radiation, NPCs, structures and
more, ported from the original 1.12.2 mod.

- Download: [CurseForge — Techguns (Unofficial Port)](https://www.curseforge.com/minecraft/mc-mods/techguns-unofficial-port)
- Support and bug reports: [Discord](https://discord.gg/zMsHAf3RK6)

## Building

Requires **JDK 17**. Like the original repository, the Gradle wrapper is not included: copy `gradlew`, `gradlew.bat`,
`gradle/` and `settings.gradle` from the [Forge 1.20.1 MDK](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
(47.x), then run `./gradlew build`. The mod jar is created in `build/libs/`.
